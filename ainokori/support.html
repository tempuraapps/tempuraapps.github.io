はじめに

iPhone だけで使えますか？

使用状況の表示には Mac アプリが必要です。AINOKORI は、Mac にインストールされた AI コーディングツールが残した記録を Mac 側で読み取り、あなたの iCloud を通して iPhone へ届けるという仕組みだからです。Mac をセットアップするまでは、アプリ内の「サンプルデータで見る」で、実際の画面と同じ形の見本をご覧いただけます。

Mac アプリはどこで入手できますか？

紹介ページからダウンロードできます。Mac App Store では配布していません。ホームフォルダに置かれたファイルを直接読み取る必要があるためです。

Mac と iPhone は同じ Apple ID である必要がありますか？

はい。データはあなた自身の iCloud プライベートデータベースを通ります。Mac と iPhone が別の Apple ID でサインインしている場合、データは届きません。

Mac を閉じている間はどうなりますか？

最後に届いた値と「最終更新」の時刻がそのまま表示されます。値を消したり、0 にしたりはしません。10分を過ぎると表示が「古い」扱いになり、30分を過ぎると「Mac オフライン」と表示されます。

表示について

大きい数字は何ですか？

「余力」＝あと何パーセント使えるかです。設定の「表示 > 数値」で「使用率」に切り替えると、使った側のパーセントになります。ウィジェットと Apple Watch もこの設定に従います。

「推定」と出るのはなぜですか？

ツールによっては、使った量は分かっても上限が公開されていません。その場合、これまでに使った最大量などから上限を推定してパーセントを出しています。推定に基づく値には必ず「推定」と表示します。Mac アプリの設定でプランを選ぶと、より近い値になることがあります。

「上限は不明」と出て、パーセントが出ません

上限を推定するだけの記録がまだ溜まっていない状態です。推測でパーセントを埋めるより、分からないと表示するほうが正確だと考えています。しばらく使うと表示されるようになります。

GitHub Copilot の数値が出ません

GitHub Copilot は利用状況を Mac 側に保存しないため、現在のバージョンでは取得できません。AINOKORI は外部のサービスへ接続しない方針のため、この状態を「取得未対応」として正直に表示しています。

リセット時刻が「不明」と出ます

枠によっては、いつリセットされるかがローカルの記録から分からないものがあります（Claude Code の週間枠など）。分からない場合に、それらしい時刻を表示することはしません。

通知

通知はいつ来ますか？

余力が設定した割合を下回ったときと、利用枠がリセットされたときです。同じ枠について繰り返し鳴ることはなく、余力が回復するまで次の通知は出ません。使っていない枠のリセットは通知しません。

Mac を使っていないのに通知が来ません

通知は、Mac から新しい値が届いたときに評価されます。Mac が起動していない間は新しい値が届かないため、通知も出ません。

AINOKORI Pro について

Pro で何ができますか？

履歴を90日分まで遡れます（無料は7日）。消費推移・平均消費速度・上限到達回数の統計、いまのペースでいつ上限に達するかの予測、通知の閾値を50・30・20・10%から選ぶ設定、1日1回のレポート、次に使う AI の提案が使えます。月額 ¥480・年額 ¥4,800 です。

無料でどこまで使えますか？

4サービスの余力とリセット時刻の表示、Mac との接続、ウィジェット、Apple Watch、7日ぶんの履歴、余力低下（20%）とリセットの通知、ライト／ダークの外観、数値の向きの切り替え、サービスの並び替えは無料でご利用いただけます。

Pro をやめると履歴は消えますか？

消えません。表示できる範囲が7日に戻るだけで、記録そのものは残ります。もう一度 Pro にすると、その間の記録もそのまま見られます。

購入したのに Pro が反映されません

アプリ内の「購入を復元する」をお試しください。購入時と同じ Apple アカウントで App Store にサインインしている必要があります。それでも反映されない場合は、お問い合わせ先までご連絡ください。

サブスクリプションを解約したい

解約は App Store 側で行います。設定 > ご自身の名前 > サブスクリプション を開き、AINOKORI を選んで「サブスクリプションをキャンセル」を選択してください。アプリ内の「サブスクリプションを管理」からも同じ画面を開けます。

解約しても、支払い済みの期間が終わるまでは Pro の機能をご利用いただけます。日割りでの返金はありません。

更新日を確認したい

上記の 設定 > ご自身の名前 > サブスクリプション で、次回の更新日と金額を確認できます。自動更新は、期間が終わる24時間以上前に解約しない限り継続します。

返金してほしい

お支払いは Apple が取り扱っており、返金の可否も Apple の判断となります。reportaproblem.apple.com から申請してください。当方では返金の手続きを行えません。

プライバシー

会話やコードは読まれますか？

読み取りません。Mac アプリが読むのは利用量の記録だけで、会話の本文・コード・認証情報・プロジェクト名やパスは、プログラムの設計上そもそも取り込めません。詳しくはプライバシーポリシーをご覧ください。

データは当方のサーバーに送られますか？

当方のサーバーはありません。Mac から iPhone への受け渡しは、あなた自身の iCloud プライベートデータベースだけを通ります。

対応環境

iPhone: iOS 18.0 以降。Apple Watch: watchOS 10.0 以降。Mac: macOS 14.0 以降（Apple Silicon / Intel）。iPad には対応していません。表示言語は日本語と英語です。
